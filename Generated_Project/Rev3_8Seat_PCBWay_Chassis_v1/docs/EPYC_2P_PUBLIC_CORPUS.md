This is a catalog of **public** 2P AMD EPYC *design-adjacent* documents (SP5 Genoa/Turin 9004/9005, plus SP3 2P and some SP6 8004/8005 1P notes where they document the same IOD/xGMI/memory ideas). It is **not** a motherboard design, **not** Gerbers, and **not** an SP5 pin map.

## What is public vs what is not

| Claim | Status | Evidence in this corpus |
|---|---|---|
| Public SP5 **TDG / MDG / PDG** (thermal, mechanical, platform design guides with land assignment) | **Does not exist publicly** | AMD forum quote: *"AMD does not publicly release the Thermal Design Guide (TDG) or Mechanical Design Guide (MDG) for SP5 / EPYC 9005 … NDA-restricted … TIP."* See thermal row below. |

| Public SP3 thermal keepout | **Exists historically; DAM URL 404 here** | AMD pub **55423** is the SP3 Thermal Design Guide. Web indexers still quote it; `amd.com/.../55423.pdf` returns HTML 404 from this environment. Do not treat 55423 as an SP5 TDG. |
| Architecture, NUMA (SP3), xGMI vs PCIe lane budget, memory population, BIOS/tuning | **Public** | AMD Documentation Hub unstructured PDFs (opened). Socket SP5/SP6 Platform NUMA Topology remains **login-gated** and is **not** listed. |
| OEM 2P motherboard/system manuals | **Public** | SuperMicro H12/H13/H14 PDFs and spec pages; Gigabyte MZ73/MZ93 systems; Dell/Lenovo/HPE/ASUS/ASRock dual SP5 PDFs; Inventec K905/K885; no public Tyan 2P SP5 board. |

**Do not design an SP5 motherboard from this list.** The public set is tuning + OEM integration manuals + architecture papers + coherent-fabric patents. Socket lands, ILM keepouts as a design kit, SVI3 VRM, and xGMI PHY routing rules for SP5 stay behind NDA.

## How URLs were verified

1. **AMD Documentation Hub sitemap** `https://docs.amd.com/sitemap/unstructured/{1,2}.xml` listed public unstructured docs. Hub pages `https://docs.amd.com/v/u/en-US/<slug>` were **opened**; when the page exposed `https://docs.amd.com/api/khub/documents/<id>/content`, that is the PDF. Some numeric PIDs (PPR zips) are large; their hub records remain if the hub metadata page itself opened and `isSecure` was false.
2. **`amd.com/content/dam/…` PDFs** were GET-verified when the CDN returned `application/pdf` (datasheets, 56683 revision guide). `55423.pdf` is HTML 404 from this VM.
3. **SuperMicro PDFs** are Akamai-403 to `curl` from this VM; they were opened with a fetch path that returns extracted manual text (CPU, DIMM, MCIO/PCIe). Spec pages such as H13DSH/H14DSG-* were opened and contain DIMM/PCIe tables (not the homepage splash).
4. **Gigabyte / Dell / Lenovo / Tyan / ASUS / HPE / ASRock / Inventec** PDFs or support HTML returned 200 or extracted text with DIMM/PCIe/xGMI facts.
5. **GitHub** HTML/raw 200. **Patents** only if the Google Patents page was opened *and* the assignee is AMD/ATI and the text is coherent-fabric / probe-filter / SERDES-lane-mux related (Intel, docking, mouthwash dropped).
6. Deduped by scheme+host+path. Japanese/Chinese locale clones of the same PID were not added (keep list was `en-US`). Alternate hub slugs of an already-listed PID (e.g. `56308_0.70_NUMA_Naples` vs the Naples NUMA title slug) were not double-counted.

## 2P-relevant facts that *are* in the public set (not pinouts)

From opened 9005 architecture overview (58462) / 5th-gen white paper / Lenovo LP1852 / Dell InfoHub xGMI DfD / HPE a50007481:

- Dual-socket uses **xGMI / G-links** on the same PHY as PCIe Gen5. Typical **4 × x16** G-links consume 64 lanes/socket → **128 PCIe lanes system-wide**. Dropping to **3 G-links** can expose **up to 160** PCIe lanes (80/socket).
- Lenovo SR665 V3 (LP1852, opened PDF): a **2xSwiftX8 cable** selects 4-link vs 3-link; theoretical bisection **512 GB/s** (4×x16@32 Gbps) vs **384 GB/s** (3×x16@32 Gbps). UEFI exposes 4-Link/3-Link xGMI Max Speed (32/25/18/16 Gbps) and xGMI Maximum/Force Link Width (x16/x8/x4). AMD XIO PHY validation tool is **NDA**.
- 2P requires **identical OPNs**; `P`-suffix SKUs are 1P-only.
- Memory: **12 DDR5 channels / socket**, 1DPC vs 2DPC speed drop is in the memory-population PDFs (9004 70593 / 9005 58463 / HPE a50007481). Some AMD *"Socket SP5/SP6 Platform NUMA Topology"* PDFs are still **login-required** (called out inside 58462). Public SP3 NUMA is 56795 (Milan).
- HPE DL385 / DX385 Gen11: **3×GMI 2P interconnect**, 24 DIMM DDR5.
- Lotes socket intro: SP5 LGA6096 **pitch 0.94×0.81 mm**, 6096 contacts, 1.4 A/pin, ILM load 152±8 kgf — still **not** a pin map.
- HSMP (69280) is a public ACPI/MMIO mailbox spec, not a board kit.
